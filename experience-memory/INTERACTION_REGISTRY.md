# Interaction Registry

Genes: Inspect, Enter, Grab, Connect, Separate, Configure, Validate, Compare, Rewind, Simulate, Approve.

Existing events include SELECT, FOCUS, HOVER, pointer orbit, zoom, dolly, layer switching, query activation, branch/confluence selection, docked inspector, and precision-surface opening.

Every interaction must declare modalities, preconditions, engine event, state target, feedback, undo/recovery, persistence, keyboard parity, non-visual parity, and reduced-motion response.
