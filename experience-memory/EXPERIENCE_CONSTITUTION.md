# Salt Basin Experience Constitution

Status: canonical candidate; changes require explicit human approval.

1. Governed meaning precedes metaphor: semantic object → experience object → representation → interaction → transition → persisted consequence.
2. Business meaning never lives only in scene-local geometry, color, or animation.
3. One governed semantic/query state is shared across journeys. Domain areas provide navigation and context; journeys and spatial views reference the shared state and must not create repeated versions of its data.
4. Spatial variants are composable visual lenses over shared state. Selecting, combining, or reorganizing lenses must not fork business state or create a second source of truth.
5. Reuse registered genes, assets, builders, patterns, and precision surfaces before creating replacements.
6. Preserve the navy, cream, gold, teal, crystalline, rod, tributary, molecule, and lineage vocabulary where governed.
7. Path identity uses the canonical path-color resolver. No second color system.
8. The world provides orientation; contextual 2D surfaces provide precision.
9. Consequential 3D objects require source lineage, state bindings, permissions, and visible agent/user action provenance.
10. Decorative objects are explicitly marked decorative.
11. Motion must communicate a declared semantic event; ambient motion cannot masquerade as state change.
12. Keyboard parity, non-visual equivalence, reduced motion, performance budgets, and graceful degradation are required.
13. Agents may create reversible candidates and prototypes, but cannot change semantic mappings, brand identity, or canonical patterns without approval.
14. Rendering is not completion. Comprehension, evidence, recovery, persistence, accessibility, and performance must pass QA.
