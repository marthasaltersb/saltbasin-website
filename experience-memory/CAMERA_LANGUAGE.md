# Camera Language

Canonical genes: `ORBIT`, `INSPECT`, `FOLLOW`, `DIVE`, `RISE`, `REVEAL`, `TRACK`, `ZOOM_TO_RELATIONSHIP`, `TIMELINE_TRAVEL`, `MACRO_TO_MICRO`, `MICRO_TO_MACRO`.

Rules: movement is bounded, interruptible, never the only signal, preserves a visible return path, restores prior context, and becomes an immediate jump/crossfade under reduced motion. Camera hierarchy follows Enterprise → Portfolio → Journey → Object → Molecule → Atom → Evidence.
