# Motion Language

| Gene | Meaning | Required reduced-motion behavior |
|---|---|---|
| FLOW | information/value progression | directional emphasis without travel |
| ORBIT | relationship/context | static relational placement |
| BOND | validated relationship | immediate connection + announcement |
| PULSE | new signal | static highlight |
| CRYSTALLIZE | definition stabilizes | immediate material/state change |
| FRACTURE | conflict | persistent conflict marker |
| BRANCH | new bounded path | branch appears without camera travel |
| MERGE / CONVERGE | reconciliation | resolved connection state |
| DISSOLVE | retirement | removed state with textual notice |
| REWIND | historical lineage | discrete historical step |
| DRIFT | unresolved state | uncertainty badge |
| EMERGE | derived governed object | immediate insertion + announcement |

Every motion record declares event, duration, easing, camera response, interruptibility, optional sound, and reduced-motion behavior.
