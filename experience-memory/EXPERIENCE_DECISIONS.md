# Experience Decisions

Status words in this ledger record Betsy's explicit review. An agent may propose a
decision but may not promote it to accepted without approval.

- `DEC-001 accepted (2026-08-10)` — Domain areas are navigation/context over one shared semantic and query state. Journeys reference that shared data; they do not create repeated domain- or journey-specific versions. Spatial variants are composable views/lenses over the shared state, not independent data stores or mutually exclusive copies. Replaces the earlier "orthogonal axes" wording.
- `DEC-002 accepted (2026-08-10)` — Compile experiences from governed registries and semantic intents; do not scatter repeated variant branches or state derivations through renderers. A contained boundary adapter may remain temporarily, but it is candidate implementation debt rather than a canonical exception.
- `DEC-003 accepted` — Extend the shared crystal geometry vocabulary instead of forking it.
- `DEC-004 accepted` — Use progressive reveal from world meaning through raw evidence.
- `DEC-005 accepted (2026-08-10)` — Derive worlds from permissions/configuration, not a hardcoded hub.
- `DEC-006 accepted (2026-08-10)` — Open tables, forms, documents, and code as contextual precision surfaces.
- `DEC-007 accepted (2026-08-10)` — Every runtime object emits a reproducible scene manifest.
- `DEC-008 accepted (2026-08-10)` — Automatic UX fixes are limited to reviewed repair recipes.
- `DEC-009 accepted (2026-08-10)` — Experience Genome composition precedes creation of new assets.
- `DEC-010 accepted (2026-08-10)` — The existing faceted crystal/agent figures become the common agent-character genealogy.
- `DEC-011 proposed (2026-08-10)` — A Dashboard Definition View may render several spatial-variant lenses together over one shared, scoped result via "one scene, N render passes" (scissor/viewport per lens), never N independent scene constructions or N WebGL canvases. Split-viewport panes may share one camera and disable click-to-select until a real Interaction Intent layer exists — a deliberate, temporary scope cut, not a permanent exception. First implementation: `src/config/experience/dashboardDefinitionRegistry.js`, `resolveDashboardComposition()`.
