## Rules that apply across every phase (obey; don't repeat inline)

- Extend, never fork: no separate app, environment or database. Reuse-first checklist before any table.
- 49 matrix families are registry rows, not tables. Sparse cell storage.
- Universal theory definitions and Salt Basin product definitions are separate, versioned records.
- Never invent Salt Basin product definitions; mark unconfirmed content `proposed` /
  `inferred — needs confirmation`; represent incomplete definitions explicitly.
- Every cross-domain definition carries an honest equivalence class; analogies are never presented as
  proven equivalences.
- Rest ≠ missing data. Unknown ≠ Pending ≠ Authorized Rest.
- Canonical identity never changes with diagram position, clef, membership, or chord composition.
- Every calculation result keeps inputs, rule versions, method, temporal context, output, validation
  status and timestamp.
- Visual edits propose changes; they never silently mutate canonical identities or contracts.
- Platform conventions: additive DDL only, append-only registries, release loop, UI/API/MCP parity,
  fictional data in public docs, `node:test` tests that run without `DATABASE_URL` for pure logic.
