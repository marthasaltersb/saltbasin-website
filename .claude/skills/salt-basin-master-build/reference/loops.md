Rules that apply across every loop (do not repeat inline, just obey them):

- **Never** rename `BestyStaff`.
- **Never** reintroduce the retired five-pillar Salter Momentum model. Canonical: UNDERSTANDING → RENDERING → MANIFESTING.
- **Never** silently change an intentional Betsy-defined term — flag it, don't rename it, until Betsy confirms.
- Classify every missed item found during a loop as one of: Foundation / schema / configuration / formula / seed data / scenario / agent rule / visual rule / simulation rule — and make the structural correction, not just a list (§96 closing instruction).
- A loop is not "done" once — re-run it whenever the codebase, Foundation doc, or Betsy's direction has moved since the last pass. Loops are meant to be repeated, not checked off permanently.
