## Rules that apply across every phase (do not repeat inline, just obey them)

- **Never preserve a displayed number merely because it already exists in code.** Every user-facing value
  must trace to a Phase 1 audit row with an explicit KEEP / REMOVE / REPLACE decision.
- **Rendering mathematics is never business intelligence.** Coordinates, camera distance, interpolation
  value, animation progress, particle velocity, and rendering radius must never be the primary label a
  user sees — keep the Rendering / Semantic / Business separation strict in every phase's output, not just
  Phase 1's audit.
- **Convergence ≠ maturity ≠ completion ≠ confidence.** These are four distinct metrics with four distinct
  meanings. The current `{pctLabel(r.maturity)} converged` label in `SpatialJourneyWorld.jsx` is exactly
  the violation this whole skill exists to fix — do not reintroduce that conflation anywhere else while
  building Phases 3–6.
- **Never hardcode a calculation weight inline in a component.** Relevance component weights, coverage
  dimension weights, and rod maturity dimension weights all route through a methodology config, never a
  literal in JSX or engine code. Run `salt-basin-config-audit` against any phase that adds a new weighted
  formula.
- **Never display a raw unrounded float with no label in the primary UI.** `d.axialDivergence.toFixed(2)`
  standing alone (as it does today) is not acceptable in the redesigned experience — every number needs a
  semantic label and, on demand, a plain-language explanation. Full unrounded precision is fine behind an
  explicit debug mode only.
- **Build against real `journey_data_rods` / `journeyEngine` data.** Synthetic values are allowed only in
  clearly labeled dev fixtures, never the production view — same rule `salt-basin-contribution-intelligence`
  already applies to its own metrics.
- **"Orbit" is canonical — resolved 2026-07-12.** The spec text originally read "Orbin"; Betsy confirmed
  this was shorthand/typo for "Orbit," matching the already-shipped term. No open naming question remains
  for Phase 7 on this point.
