## Open decisions requiring a Betsy answer (do not default — see reconciliation memo §5 for full framing)

1. Is the three-way `authorityProfileIds` / `moduleAccessProfileIds` / `viewAccessProfileIds` split real near-term need, or should it collapse into extending `data_entitlements.scope` (the lower-risk path, and what the Member Portal Crystal & Agentic Layer spec already assumes)?
2. Are the spec's two visibility enums (§3 object-level `PRIVATE/MEMBER_ONLY/ORGANIZATION_VISIBLE/SHARED_BY_LINK/PUBLIC` vs. §15 record-level `MEMBER_PRIVATE/MEMBER_PUBLIC/ORGANIZATION_PRIVATE/ORGANIZATION_SHARED/CROSS_ORGANIZATION_AUTHORIZED/PUBLIC`) one taxonomy at two granularities, or two genuinely separate concerns?
3. Should Member-scoped Channel Rods (Cash Liquidity, Spending, Unsecured Debt, Credit Health, Reimbursement) be added to the Foundation's canonical Channel Rod list now, or held until Phase 4's financial-connection infrastructure actually exists?

## Rules that apply across every phase (do not repeat inline, just obey them)

- This is a **subset driver**, not a competitor to `/salt-basin-master-build` — it exists because this companion spec is a prerequisite identity/access/personal-config layer that master-build loops 2, 3, 6, 7, and 16 assume exists. Running a pre-build phase satisfies the corresponding note in `salt-basin-master-build/reference/loops.md`; it doesn't duplicate it.
- Never rename `BestyStaff`.
- Never silently change an intentional Betsy-defined term — flag it, don't rename it, until Betsy confirms.
- Follow CLAUDE.md's deployment-safety invariants exactly: append-only block registry, additive-only shared config rows, schema-versioned JSON, seed/bootstrap never touches member rows.
- A phase is not "done" permanently — re-run it whenever the codebase, Foundation doc, or Betsy's direction has moved since the last pass.
- Do not enter financial credentials, tokens, or account numbers anywhere — Phase 4 builds connection *infrastructure* (OAuth/Plaid-style flow code), never performs an actual account linking on Betsy's behalf.
