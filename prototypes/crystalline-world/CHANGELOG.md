# Changelog

## Gameplay

- Preserved three rods, stage navigation, Ride, Deal Points, conflict resolution, quest, event action, World and Build modes.
- Added Shard follow/progression, five future locked districts, governed infrastructure choices, operational tasks, and five simulator routes.
- Added resources for Evidence, Trust, and Build Capacity in state while keeping the HUD compact.

## UI

- Added a responsive stage rail, companion card, Data Story, Tasks, Simulator, Settings, Build tray, stage-arrival status, and compact performance overlay.
- Added touch-sized mobile controls, scrollable modals, Escape dismissal, focus-visible states, ARIA labeling, and live-region announcements.

## Scientific rendering

- Expanded all seven crystal-system entries with axes, angles, coordination, habit, facet strategy, growth, cleavage, and deformation guidance.
- Added `projectOperationalStateToCrystal()` and maturity growth tiers.
- Added visible re-crystallization after reinforcement or conflict resolution.
- Added evidence, lineage, relationship, validation, and contested-state projection measures.

## Performance

- Preserved capped pixel ratio and shared scene systems.
- Added mobile dust limits, visibility pause, selective relationship rendering, and optional FPS/draw-call/triangle overlay.

## Accessibility and reliability

- Added guarded WebGL/Three.js startup, visible startup errors, global error/rejection handlers, one-time Enter binding, pointer/touch/keyboard activation, and reduced-motion support.
- Added versioned localStorage state with corrupt-save fallback and reset/export controls.
