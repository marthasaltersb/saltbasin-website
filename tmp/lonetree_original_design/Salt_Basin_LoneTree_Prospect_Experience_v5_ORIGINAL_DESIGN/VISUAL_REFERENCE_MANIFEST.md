## Adding another visual

Provide the original-resolution file or the page/slide/sheet containing it, then record:

- Source filename
- Reference name
- Authority: canonical, supporting, or illustrative
- Target portfolio section and HTML tab
- Concepts/arrows/labels that must be preserved
- Decorative detail or example numbers that may be simplified
- Claim or confidentiality constraints
