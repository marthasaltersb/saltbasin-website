CANVA VISUAL SOURCE COMPANION 04 / 04
Canva Prompt Addendum
Attach this page's language when asking Canva to use the visual companion
Suggested add-on prompt
Use the uploaded Visual Metadata Iconography Companion as the design vocabulary for the resume package. Do not copy it as a page layout. Borrow its executive
palette, icon meanings, metadata chips, quantified proof badges, and capability-map structure.
Represent metadata visually:
Use small line icons beside bullets to show evidence type: revenue impact, systems architecture, process design, data/integration work, PE value creation,
AI-native product/operator work, leadership, and QA.
Use compact chips for employer, industry, scenario, role, and metric metadata.
Turn dense evidence into clean callout badges where the source files include measurable scale, ARR, program size, exits, stakeholder counts, integrations, team
size, or product volume.
Keep the tone premium, executive, precise, and non-decorative. Use white background, deep navy, muted gold, slate, and restrained green/teal accents.
Preserve light text on dark backgrounds. Never place dark text on navy, charcoal, maroon, green, or other dark fills.
Best additional output to keep
This file should travel with the two evidence PDFs whenever Canva is asked for a polished resume, because it tells Canva how to render the metadata graphically without disturbing the
source documents.
