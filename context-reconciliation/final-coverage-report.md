# Architecture reconciliation coverage

## Definition of Done

The master migration is **Done** only when all of the following are true and verified against real Salt Basin data:

- Canonical schema and temporal governed-object persistence exist.
- Legacy terminology inventory and record-level migrations are complete and reversible.
- Existing business scenarios have explicit coverage dispositions.
- Revenue, Customer, and Member Journey Rods are configuration-driven.
- Every Journey Branch candidate has been semantically classified; true divergences are Tributaries with Confluences.
- Evidence is persisted; compositions, settlement, journey position, accounting projection, and divergence are derived with rule/version lineage.
- Settlement and resuspension are projection-relative and preserve constituent evidence.
- Accounting topology performs reciprocal inference against the same economic compositions.
- Agent Boundaries are persistent, object-scoped, policy-governed, and auditable.
- Every renderable semantic object resolves layer, object type, identity, geometry, material, color, outline, lighting, and opacity through central registries.
- The Legend Explorer uses the production renderer and Visual Semantic Registry.
- Visual Debug Mode exposes canonical identity and source paths.
- Required seeds and scenario tests pass, including all seven accounting/resuspension scenarios.
- Three context reconciliation passes produce no unexplained gaps.

## NOT Done

The migration is **not Done** when any of these substitutes are presented as completion:

- Architecture documents, schemas, or empty registries without working data migration.
- Global branch-to-Tributary or merge-to-Confluence find-and-replace.
- A Three.js scene whose objects do not resolve to canonical governed objects and real lineage.
- Floating glass cards, particles, decorative crystals, rails, or generic nodes/edges presented as semantic architecture.
- A manually maintained legend or PNG/icon proxy instead of the production renderer.
- Maturity, confidence, risk, or one generic score relabeled as settlement or journey position.
- Hardcoded journey stages, atom types, compositions, accounting policies, or visual semantics in React components.
- Synthetic scale data replacing Salt Basin data as the default experience.
- Deleted/replaced evidence, lost rejected Confluence contributions, or unversioned derived-state overwrites.
- Unreported gaps, skipped scenario tests, or a successful build used as proof of business correctness.

It is **an implementation increment, not completion of the master migration**. Blocking gaps are enumerated in `uncovered-context-register.json`.
