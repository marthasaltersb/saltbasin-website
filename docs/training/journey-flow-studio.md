# Training spec — Journey flow studio: a metadata-driven, persisted, downloadable process flow builder

Audience: a test agent driving a real browser as a member, once as an administrator, plus a few command-line steps. Every step says exactly what to do and what you should see. All data is fictional (flows **Seed Shop Orders**, **Seed Packet Returns**, **Pilot Check**; a returns desk selling garden seed packets). Everything happens inside the World Shell (`/world`); no admin URL is typed.

Version 1 · 2026-10-11 · every journey names its UI path, API route and MCP tool on its `Interfaces:` line (the MCP tools call the same functions as the routes) · change spec: `docs/changes/journey-flow-studio.md`

## Where things are

- **World Shell**: `/world`. Top bar tabs **World**, **Journeys**, **Classic Tools**. The **Journeys** tab is a list of cards. The card **Journey Flow Studio** opens the studio full screen with **← Back to World** at the top left.
- **Studio home** (heading **Journey Flow Studio**): tabs **Flows**, **Templates** and, for administrators only, **Settings**. A line under the tabs shows a **confirmation line** (a pale blue box) with the result of your last action, or a red box (role alert) with a plain-words error.
  - **Flows** tab: the card **New flow** (fields **New flow name** and **Start from**, button **Create flow**), the card **Import a flow** (field **Paste flow JSON**, button **Import flow**, a file chooser **Or choose a .json file**), then **Your flows**: one button per flow showing its name and a line `Version n · draft` or `Version n · published`. With no flows the text is **No flows yet. Create one above, or start from a template.**
  - **Templates** tab: one card per template with its name, a line (`Seed template` or `Template · Only me` / `Template · My organization` / `Template · Whole platform`), a description, and the buttons **Use template**, **Export JSON**, **Export HTML viewer** and, on templates you own, **Delete template**.
- **Flow editor** (opens when you create or open a flow): a top row with **← All flows**, the fields **Flow name** and **Domain or channel (L1)**, the line `Version n · draft|published`, then the buttons **Save draft**, **Undo**, **Redo**, **Publish**, **History**, **Export**, **Save as template**. Next row: **Current state**, **Future state** (the pressed one is the state you are drawing), the list **Scenario** (first option **Base (L2)**), the field **New scenario name** with **Add scenario**, and **Lanes**. Next row: the add buttons **Add Step**, **Add Sub-process**, **Add Decision**, **Add Parallel gate**, **Add Event**, **Add Data object**, **Add Start / End**, then the modes **Select**, **Connect**, **Delete mode**.
  - The drawing (swimlane bands with their names at the top-left of each band; shapes with a darker offset copy behind them for the 3D effect; arrows with their path label in a small pill) scrolls inside its own box.
  - Below the drawing: the card **Steps and connectors** (the same flow as a list; one button per step, text `<Shape>: <label>` such as **Step: Check stock by hand**, and under each step one indented button per outgoing connector, text `→ <target label>` plus ` (<path label>)` when it has one and ` [loop]` for a self-loop), then the card **Check flow** (a coloured pill: `no problems`, or `n error(s), m warning(s)`, and one line per finding).
  - On the right (below on a phone) the **Inspector**: with nothing selected it says **Select a step or a connector to edit it. Tap Connect, then two steps, to draw an arrow.**
- **Tapping, not hovering.** On a phone, and wherever the drawing is awkward, select steps and connectors from **Steps and connectors**. In **Connect** mode tapping two steps in that list draws the arrow from the first to the second (tap the same step twice for a loop); the new connector is selected automatically. **Select** returns to normal. In **Delete mode** tapping a step in the list deletes it and its connectors.
- Badges on a drawn step: a round badge at its top-left reads **U** (User activity), **S** (System automation) or **H** (Hybrid); a small pill at its top-right reads **||** when Dependency is Parallel; a gold dot marks a step with any saved field, a red dot a Current-state step with a pain point, handover gap or leakage scenario, a green dot a Future-state step that resolves a Current-state problem.
- **Step panel** (heading `Step: <label>`): **Label**, **Shape**, **Execution** (Not set, User activity, System automation, Hybrid), **Dependency** (Sequential, Parallel), **Scenario tags**, then field groups **Identity & hierarchy**, **Actors & data flow**, **Authority & system**, **Architecture & data**, **Experience**, **Experience binding**, and **Current-state diagnostics** (Current state) or **Future-state tracking** (Future state), then **Draft with agent** and **Delete step**. **Connector panel** (heading `Connector: <from> → <to>`): **Path label**, **Branch parameters**, **Branch notes**, **Connector scenario tags**, an **Overrides for <scenario>** group while a scenario is chosen, **Draft with agent**, **Delete connector**.
- Time and text formats: the History list shows `YYYY-MM-DDTHH:MM:SS.sssZ` timestamps; match the words, not the times.
- Phone width: the same screens at 390px wide, one column; every control is at least 44px tall; the page never scrolls sideways (only the drawing box does).

Fixed test constraints that apply to every step: fresh database; the test accounts from `scripts/create-test-member.mjs`: the member **member@test.local** (display name **Test Member**) and the administrator shown as **admin@test.local**, both password `TestPass!2345` for the member (the administrator uses the seeded admin password), terms accepted. Two browser windows may be open at once (MEMBER WINDOW and ADMIN WINDOW); each journey says which one. Steps run in order; a flow made in one journey is reused by later journeys. Expected non-2xx responses (anything else is a failure): none in the browser; the CLI steps in Journey 13 and the edge cases name theirs. External font/CDN requests may fail offline and `favicon.ico` may 404; ignore those.
