# Salt Basin — Canonical Artifact Set

This folder is the canonical source of truth for Salt Basin Holdings architecture, terminology, data model, and product definitions. It was synthesized from all prior sources (foundation SOT, workbooks, session transcripts, live code, and the LoneTree proposal) into a governed artifact set.

**These are documentation artifacts, not application code.** They live alongside the website repo so the canon travels with the codebase, is versionable in Git, and can be handed to a developer or agent as authoritative context. Nothing here is imported by the Vite app.
