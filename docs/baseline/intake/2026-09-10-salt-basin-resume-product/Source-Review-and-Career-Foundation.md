## Process flow compatible with the supplied template

Use the ten fields in S06: Template Key, Template Name, Step Order, Step Label, Shape Type, Execution Mode, Event Subtype, Domain, Connects To, Branch Label. Proposed template key: `career-evidence-l2`.

1. Receive career account — event, hybrid, itemCreation.
2. Extract candidate claims — step, automated.
3. Review facts and sources — step, manual.
4. Facts sufficiently resolved — decision, hybrid; branch to 5 or return to 1 for additions.
5. Capture target requirements — step, hybrid.
6. Map and assess evidence — step, hybrid.
7. Evidence sufficient for proposed wording — decision, hybrid; branch to 9 or 8.
8. Collect user's transfer reasoning and new examples — step, manual; return to 2.
9. Draft selected output family — subprocess, automated.
10. Review factual changes and layout — step, hybrid.
11. Approve specific version — decision, manual; branch to 12 or return to 9.
12. Export approved version — terminal, automated.

S06 provides one Branch Label per row despite permitting multiple outgoing edges. That cannot unambiguously label both "sufficient" and "needs more evidence" on the same decision. Preserve the existing file and propose a separate edge table (`from_step`, `to_step`, `condition`, `label`) or intermediate branch-label steps for implementation. Do not copy the sample's "Auto-approve" behavior into career fact approval.
