## Known gaps

- Per-block field contracts (each block's `fields` keys) are not enumerated. CLAUDE.md notes there is no CTA naming convention across blocks. A field-level inventory would require reading `blocks/index.jsx` (5,854 lines) block by block. That is planned but not started.
- Accessibility (contrast per theme, focus states, ARIA) is unassessed.
